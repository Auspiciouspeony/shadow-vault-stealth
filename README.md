Shadow Vault is a top-down stealth heist game: slip past the night wardens' vision cones, steal every relic in three moonlit galleries, and reach the exit unseen. Sneak, hide in the plants, toss coins to distract patrols — get spotted and the alarm chases you down.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser and play with keyboard and mouse. WASD / arrows move, Shift sneaks, click tosses a coin, P pauses, M mutes. `main.ts` hands the game in: `MAKEFUN_OUTPUT_DIR=out node main.ts` copies game/ and screenshots/ and writes out/dossier.json.
