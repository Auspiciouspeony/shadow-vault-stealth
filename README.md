Shadow Vault is a top-down stealth heist game: slip past the night wardens' vision cones, dodge sweeping security cameras and blinking laser tripwires, steal every relic across five moonlit heists, and reach the exit unseen. Sneak, hide in the plants, toss coins to distract patrols, throw smoke bombs to blind every eye — get spotted and the alarm chases you down. Three strikes and the heist fails.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser and play with keyboard and mouse. WASD / arrows move, Shift sneaks, click tosses a coin, Q throws a smoke bomb, P pauses, M mutes. `main.ts` hands the game in: `MAKEFUN_OUTPUT_DIR=out node main.ts` copies game/ and screenshots/ and writes out/dossier.json.
